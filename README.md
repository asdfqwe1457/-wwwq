# 民宿酒店项目全套开源系统

源码地址：ym7k.com/20084/

民宿、精品客栈与中小型酒店的经营，涉及房源管理、在线预订、房态管控、入住接待、账单结算、客诉维护等繁杂事务，传统手工登记方式容易出现超售、台账混乱、对账麻烦等问题。一套完整的民宿酒店开源系统，围绕房源上架、预订下单、房态管理、入住退房、财务管理、会员营销、运维统计全流程搭建功能体系，支持独立部署和二次开发，适合民宿主、小型客栈、连锁精品酒店搭建自主可控的住宿运营平台。

房源与房型管理是系统的基础模块。后台可以录入多种房型信息，比如大床房、双床房、家庭套房、庭院房等，每个房型配套图片、视频、面积、容纳人数、配套设施、退房规则、取消政策等详情。支持设置多套价格方案，区分平日价、周末价、节假日溢价，还能配置长租优惠、连住折扣。每一间独立客房都有单独档案，记录房间配套物品、维护记录，房态实时同步，分为空闲、已预订、入住中、待打扫、维修中，从源头避免一房多卖的超售问题。同时支持配套增值服务上架，例如接送服务、早餐、保洁、团建配套等，供客人下单选购。

预订下单与订单管理是核心业务功能。客人可以在前端查看房间介绍、日历房价，自主选择入住和离店日期，提交预订订单，填写入住人信息。系统支持设置预订审核模式，既可客人直接支付锁定房间，也可由店主人工确认后再生效。订单生成后自动锁定对应房间，同步更新房态。支持订单修改、取消、改期操作，按照预设规则自动核算违约金，所有变更记录留存。店主可以查看全部订单，按入住时间、房型、订单状态筛选检索，方便提前安排接待工作。

入住退房、前台接待模块适配线下服务流程。到店之后，前台可调取订单信息，登记入住人身份信息，支持押金收取、登记备注。退房时一键结算，自动核算房费、增值服务费、消费扣款，生成明细账单。支持多种结算方式，完成退款操作。房间状态同步流转为待打扫，自动推送提醒给保洁人员。保洁完成打扫后更新房态为干净可售，形成闭环流转，提升客房周转效率。

会员营销与消息通知助力持续经营。系统支持会员体系搭建，客人注册成为会员后可享受折扣、积分，积分可抵扣房费或者兑换增值服务。后台可发布优惠券、限时特惠套餐，用于淡季引流。同时内置消息提醒机制，预订成功、入住提醒、退房提醒、评价通知都会推送，方便客人和店主及时接收信息。客人入住结束后可以提交评价，店主能够回复评价，维护口碑。

权限管控与数据看板支撑运营决策。系统设置多角色权限，店主、前台、保洁、财务拥有不同操作权限，前台仅处理入住退房，财务负责对账结算。数据看板直观展示入住率、营收数据、热销房型、客源时段、差评统计等数据，帮助经营者合理调整定价、优化淡旺季营销策略。

这套开源民宿酒店系统打通房源上架、预订、接待、退房结算的完整业务链路，不再受制于第三方 OTA 平台高额佣金和流量约束。运营者可以基于源码灵活调整功能，适配乡村民宿、城市公寓、小型客栈等场景，标准化住宿业务流程，降低人工管理成本，提升客人入住体验。
